MochiiTracer · Protogen OS - third-party notices for the firmware (.hex)
=========================================================================

The .hex files of each release are built from this repository, which is under the GNU Affero
General Public License v3.0 (see LICENSE and NOTICE.md). Each .hex also contains compiled code
from the components listed below. Their source code is not part of this repository: PlatformIO
downloads it when you build (see platformio.ini). This file reproduces the notices their
licenses ask to ship together with binaries, and every release carries it next to the .hex
files, together with LGPL-2.1.txt and the OFL-1.1-*.txt font licenses.

The complete source code of the firmware is in this repository, and the libraries below are
published by their authors (PlatformIO registry, GitHub, pjrc.com), so you can change any of
them and build a new .hex with `pio run -e teensy40hub75`.

6. Fusion Pixel Font (Chinese glyphs of the inner OLED)
-------------------------------------------------------

The Chinese characters of the OLED are bitmaps of Fusion Pixel Font 12px zh_hans
(Copyright (c) 2022, TakWolf), whose glyphs come from Ark Pixel Font (Copyright (c) 2021,
TakWolf) and Cubic 11 (built on JF Dot M+H 12, Copyright (c) 2005 M+ FONTS PROJECT, and the M+
bitmap fonts, Copyright (C) 2002-2004 COZ). They are under the SIL Open Font License 1.1: see
OFL-1.1-fusion-pixel-font.txt, OFL-1.1-ark-pixel-font.txt and OFL-1.1-cubic-11-font.txt.


7. Compiler runtime
-------------------

The .hex also contains small parts of the C/C++ runtime of the GNU Arm toolchain that PlatformIO
uses (libgcc and libstdc++, under the GPL v3 with the GCC Runtime Library Exception, and the
newlib C library, under the licenses listed in its COPYING.NEWLIB file).
